# concept

Six pages holding the distinctions everything else in this wiki is written on top of. A `source`
page says `cite_only` and expects you to know that this closes one operation and leaves two open. A
`practice` page says "assemble the attribution block" and expects you to know the credit line is a
property of the record, not of the host. This family is where those assumptions are stated.

You want it **before** the first fetch, not after. Five of the six pages describe an error that is
made at the framing stage and is invisible afterwards: asking "is this source open" as one
question, dropping a restrictive source, storing one attribution string per host, reusing a
licensed page's figures under that page's verdict, trusting a footer over material the host plainly
did not make.

You also want it when someone hands you a verdict and you need to know whether it is answering the
right question. "We cannot use MARS because it is NonCommercial" is wrong at the operation level
twice over, and this family is where that becomes visible without opening the host page.

The sixth row is different in kind. [[concept-standard-placement-vs-code]] is a data-model fact
about the standards store, not a rights concept, and it sits here because it is the same shape of
error: a plausible empty result that a competent person reads as an answer.

## Pick a page

**Ordering: the order a build meets them.** What operation are you performing, what posture are you
holding while you read, what does the credit line say, what inside the work is outside the grant,
did the licensor have it to give. The store row is last because it is the only one that is not
about rights.

| Page | What error it prevents |
|---|---|
| [[concept-cite-quote-adapt]] | Asking "is this source open" as one question. Citing needs no licence, quoting does not trigger ShareAlike, and only paraphrase-and-republish is what the riders bite on. |
| [[concept-curate-and-cite]] | Dropping a source because its licence is restrictive. Its design layer, item taxonomies and distractor maps and rubric grammars, is not protected expression, and this project wrote IM off once by making exactly that move. |
| [[concept-attribution-per-record]] | Storing one attribution string per host. CC BY 4.0's duty is to retain what the licensor supplied **with that material**, and a plausible credit line renders exactly like a correct one. |
| [[concept-third-party-carve-out]] | Reusing a licensed page's figures under that page's verdict. The trademark and third-party-image carve-outs are sentences in the same footer as the grant. |
| [[concept-chain-of-title]] | Trusting a blanket site-wide grant that sits above per-item bylines naming other people. A licence cannot convey rights the licensor does not hold. |
| [[concept-standard-placement-vs-code]] | Treating a standard code as a key. 693 of 794 codes resolve to more than one placement, so an empty facet usually means you are on the wrong placement, not that the data is absent. |
