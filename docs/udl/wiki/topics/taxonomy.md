# Taxonomy and Synonyms

Cross-cutting vocabulary, and the mappings you need when this wiki and another
resource use different words for the same thing.

## Version 2.2 to 3.0

The single most useful table here. Version 3.0 was released 30 July 2024; most UDL
material online, and most training people received, describes 2.2.

### Structural vocabulary

| 2.2 | 3.0 | Note |
|---|---|---|
| Checkpoint | **Consideration** | The third level. "Checkpoint 7.1" and "consideration 7.1" are the same node. |
| Provide options / Provide multiple means | **Design options** / **Design multiple means** | The verb changed from providing to designing. |
| Expert learners | **Learner agency** | Not a rebrand. See [[learner-agency]] for the stated reasons. |
| Access / Build / Internalize | **Access / Support / Executive Function** | The row axis. See [[access-support-executive-function]]. |

### Guideline names

| 2.2 | 3.0 |
|---|---|
| Comprehension | [[building-knowledge]] (3) |
| Physical Action | [[interaction]] (4) |
| Executive Functions | [[strategy-development]] (6) |
| Recruiting Interest | [[welcoming-interests-and-identities]] (7) |
| Self-Regulation | [[emotional-capacity]] (9) |

Unchanged: [[perception]] (1), [[language-and-symbols]] (2),
[[expression-and-communication]] (5), [[sustaining-effort-and-persistence]] (8).

**Consideration-level mappings between 2.2 and 3.0 are not published.** CAST refers to
a side-by-side comparison available on request; the public document was not located
during this build. So a 2.2 checkpoint number cannot be reliably translated into a 3.0
consideration number here. Match by name and content, not by number.

## The framework's four levels

| Level | Count | What it is |
|---|---|---|
| Principle | 3 | The broadest division. Why / what / how. |
| Guideline | 9 | A principle crossed with a row. |
| Consideration | 36 | The actionable node. |
| Design option | many | Concrete strategies inside a consideration. Page content in this wiki, not separate pages. |

## Terms that are folk-UDL

Widely used by practitioners, absent from CAST's formal published definitions. Useful
ideas; not the framework. Flagged wherever they appear.

| Term | Status |
|---|---|
| Content standards vs method standards, and the diagnostic question "is this requiring all students to do the exact same thing in the same way?" | **The most consequential entry in this table.** Novak Education's operationalization of a CAST principle, not CAST's own categories. CAST states the underlying principle (focus on the learning goal to find construct-irrelevant barriers); the two-category split, the verb lists, and the diagnostic question are a commercial consultancy's framing. See [[firm-goals-flexible-means]] and [[apply-udl-to-a-standard]], which both depend on it. |
| Jagged learning profile | Practitioner and advocacy usage. See [[learner-variability]]. |
| Designing for the edges | The idea is present in CAST's thinking; this phrasing is not CAST terminology. |
| Plus-one | Incremental adoption is real; this label is not CAST's. See [[implement-udl-at-school-scale]]. |
| Curb-cut effect | Endorsed in spirit, not formally attributed in CAST materials. See [[universal-design-origins]]. |

## Measurement and assessment vocabulary

Precision matters here; these are not loose synonyms.

| Term | Meaning | Page |
|---|---|---|
| Construct | What is actually being learned or measured | [[firm-goals-flexible-means]] |
| Construct-irrelevant variance | Score variance from factors irrelevant to the construct | [[construct-irrelevant-variance]] |
| Construct-shift | Changing what is measured, not just how. Not UDL. | [[lowering-rigor-in-the-name-of-flexibility]] |
| Accommodation | Changes HOW a construct is demonstrated; preserves comparability | [[construct-irrelevant-variance]] |
| Modification | Changes WHAT is measured; generally breaks comparability | [[design-an-accessible-assessment]] |
| Fidelity | Whether an intervention was actually implemented as specified | [[measuring-udl-implementation-fidelity]] |
| Reliability vs validity | Consistent measurement vs measuring the right thing. Not interchangeable. | [[measuring-udl-implementation-fidelity]] |

## Accessibility vocabulary

Legally distinct from UDL vocabulary. Keep them apart.

| Term | What it is |
|---|---|
| WCAG | Web Content Accessibility Guidelines. Testable success criteria, conformance levels A / AA / AAA. |
| Section 504, ADA Title II | US civil-rights obligations, enforceable. |
| IDEA / IEP | US special-education statute and the individual plan it requires. Does not mention UDL. |
| NIMAS | Standard for accessible instructional materials. |
| Assistive technology | Tools a learner uses to access or produce. |

The boundary these terms mark: [[mistaking-udl-for-accessibility-compliance]] and
[[assuming-udl-replaces-accommodations]].

## Adjacent frameworks

Related, frequently conflated with UDL, and not the same thing.

| Framework | Relationship |
|---|---|
| Differentiated instruction | Reactive response to identified learner needs. [[confusing-udl-with-differentiated-instruction]] |
| MTSS / RTI | Tiered support systems. UDL is positioned as universal design at Tier 1. |
| SEL / CASEL | Overlaps [[emotional-capacity]] in substance. CAST does not name SEL or CASEL in the fetched Guideline 9 pages. |
| WIDA | Language-development framework for multilingual learners. Complementary. [[understanding-across-languages-and-dialects]] |
| Learning styles | **Not** a UDL framework, and the confusion is consequential. [[udl-and-the-learning-styles-problem]] |
