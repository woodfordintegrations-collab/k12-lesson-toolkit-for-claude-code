# 6.3 Organize Information and Resources

## Summary

Consideration 6.3 sits under [[strategy-development]] (Guideline 6) in
[[multiple-means-of-action-and-expression]]. It targets working memory specifically
(CAST's own metaphor is a "scratch pad") and asks for organizational scaffolds
**only when holding information in mind is not itself what the task is measuring.**
That qualification is the substance of the consideration, not a footnote to it.

## When to reach for it

Reach for 6.3 when a learner has the information they need but cannot hold enough of
it in mind at once to work with it, and when that capacity is not the thing you are
trying to teach or test.

| The actual problem | Where to go instead |
|---|---|
| They cannot perceive or access the information at all | [[multiple-ways-to-perceive-information]] (1.2) |
| They have the information but can't tell what in it matters | [[patterns-critical-features-and-big-ideas]] (3.2) |
| The task's actual construct *is* holding information in working memory | Not this page; see the bound below |
| They can organize a single source but not plan across a multi-step project | [[anticipate-and-plan-for-challenges]] (6.2) |
| They've organized their materials but can't tell if they're making progress | [[monitoring-progress]] (6.4) |

## How it works

CAST's definition:

> Working memory functions like a "scratch pad" for maintaining information chunks
> needed for knowledge building and problem-solving. When working memory capacity
> isn't directly relevant to learning objectives, educators should employ various
> scaffolds and organizational aids to help learners maintain organized information.

The bound is explicit and load-bearing: scaffold organization **when working memory
capacity isn't directly relevant to learning objectives.** This is
[[firm-goals-flexible-means]] applied to working memory specifically. If the goal
being assessed is something else (synthesizing a set of sources, say) and holding
them all in mind is incidental overhead, a graphic organizer is a legitimate
accommodation. If the goal itself is the capacity to hold and manipulate information
without external aids, the same organizer erases the construct being measured. See
[[construct-irrelevant-variance]] for the general form of this test.

**On the construct itself:** working memory is a real, extensively studied cognitive
construct, and this page does not import a mechanism for it. CAST's source describes
it only with the "scratch pad" metaphor and does not cite a specific working-memory
literature on this page, so nothing more specific than that metaphor is asserted
here. Where CAST does not name a mechanism, this page does not supply one from
memory.

## In practice

CAST's design options for 6.3, the shortest list of the five considerations in this
guideline:

- Use graphic organizers and templates for data collection and organizing
  information.
- Use prompts for categorizing, systematizing, and discovering themes and patterns.
- Use checklists and guides for note-taking.

**A worked pass.** A lab report is meant to assess understanding of an experimental
method, not the ability to hold five procedural substeps in mind at once: a graphic
organizer for recording each step's data (design option one) is fair scaffolding
under 6.3's own bound. Contrast a task built specifically to check whether a learner
can mentally track several quantities at once without writing them down: there, the
same organizer would remove the thing being measured, and 6.3 does not license using
it. The difference is not in the tool; it is in what the goal names as the construct.

## Gotchas & constraints

- **This is the thinnest of the five considerations in the staged source:** three
  design options against four to six elsewhere in Guideline 6, and no additional
  elaboration beyond the single definition paragraph. That thinness is reported as a
  property of the source, not filled in from elsewhere.
- **The bound is easy to skip past.** "Scaffold working memory" reads as an
  unconditional instruction if you do not carry forward the "isn't directly relevant
  to learning objectives" clause. Always check what the goal is measuring before
  applying this consideration.
- **The source's research link was not retrieved**; no findings are reported for the
  same reason as elsewhere in this guideline: none were staged.
- **Do not import a working-memory mechanism CAST doesn't state.** The "scratch pad"
  language is the framework's own metaphor, not a citation to a specific model of
  working memory.
