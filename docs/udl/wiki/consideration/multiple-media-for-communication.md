# 5.1 Use Multiple Media for Communication

## Summary

Consideration 5.1 sits under [[expression-and-communication]] in the Action & Expression
principle, [[multiple-means-of-action-and-expression]]. CAST's overview page condenses it
to express learning in flexible ways. It concerns the **medium a learner uses to show what
they know** (text, speech, drawing, film, dance, sculpture), not the tools used within a
medium (that is 5.2) and not the material the learner is given to work with (that is a
different guideline entirely).

## When to reach for it

Reach for 5.1 when a learner understands the material but the required output format is
itself the obstacle, and that format is not what is actually being assessed.

| The actual problem | Where to go instead |
|---|---|
| The material coming *in* needs multiple formats, not the learner's output | [[illustrate-through-multiple-media]] (2.5) |
| They have a medium but lack the tools to execute in it (word processor, CAD, notation software) | [[tools-for-construction-and-composition]] (5.2) |
| They can pick a medium but need scaffolded practice to perform well in it | [[build-fluencies-with-graduated-support]] (5.3) |
| The medium is technically available but treated as less legitimate | [[biases-in-modes-of-expression]] (5.4) |
| The standard being assessed is a writing standard | [[firm-goals-flexible-means]], [[lowering-rigor-in-the-name-of-flexibility]] |

That last row is the one to check first. 5.1 and 2.5 get confused constantly because
CAST uses nearly identical language for both: "multiple media" appears in both titles.
They run in opposite directions: 2.5 is about **representation**, material being shown
*to* the learner; 5.1 is about **expression**, the learner producing something *from*
themselves. A learner watching a video explanation instead of reading text is 2.5. The
same learner recording a video explanation instead of writing an essay is 5.1. Confusing
the two means designing the wrong side of the interaction.

## How it works

CAST's claim carries its own exception, and the exception is the substance:

> Unless specific media and materials are critical to the goal (e.g., learning to paint
> specifically with oils, learning to hand write with calligraphy), it is important to
> welcome and encourage a variety of media for expression.

Three things this accomplishes, per the source: it reduces media-specific barriers for
learners with disabilities, it honors communication forms that have been historically
devalued (the throughline into [[biases-in-modes-of-expression]]), and it expands
expressive opportunity in a media-rich world.

The framing CAST gives is broader than "writing plus alternatives." The description
notes the focus is on teaching **composition** broadly, not just writing, and on helping
learners select the optimal medium for their content and audience: the choice of medium
is itself a skill being built, not just a workaround.

## In practice

CAST's design options, listed under this consideration:

- Compose in multiple media such as text, speech, drawing, illustration, comics,
  storyboards, design, film, music, storytelling, dance/movement, visual art,
  sculpture, or video.
- Use physical manipulatives (e.g., building blocks, 3D models, base-10 blocks).
- Use social media and interactive web tools (e.g., discussion forums, chats, web
  design, annotation tools, storyboards, comic strips, animation presentations).
- Solve problems using a variety of strategies.

**A worked pass.** A unit asks learners to explain the causes of a historical event.
If the goal is *demonstrate understanding of causation*, the medium is means: a
video essay, a storyboard, or an oral presentation can all carry the same reasoning,
and 5.1 is fully open. If the assignment sits under an ELA standard that specifically
assesses written argument structure, the medium is the construct: opening it changes
what is being measured, and the case belongs to
[[lowering-rigor-in-the-name-of-flexibility]], not here. CAST's own exception (oils,
calligraphy) is the same move: some goals genuinely require the medium. See
[[apply-udl-to-a-standard]] for reading standards language to tell the two cases apart.

## Gotchas & constraints

- **This is not 2.5, and the confusion is common enough to name directly.**
  Representation (2.5) varies what the learner receives. Expression (5.1) varies what
  the learner produces. Check which direction the barrier runs before reaching for
  either page.
- **Where the medium is the construct, opening it is construct-shift, not UDL.** A
  writing standard assessing writing is not made more accessible by letting learners
  submit a video instead. It is being assessed on something else. See
  [[firm-goals-flexible-means]].
- **A media-rich option set is not automatically an accessible one.** A video-composing
  tool can itself have access barriers a text editor does not; opening the menu of
  media does not substitute for checking each option against
  [[access-to-assistive-technologies]].
- **CAST's own exception list (oils, calligraphy) is a reminder, not an edge case.**
  Some fraction of any curriculum genuinely ties the goal to the medium; the design
  question is which fraction, not whether the exception exists.
