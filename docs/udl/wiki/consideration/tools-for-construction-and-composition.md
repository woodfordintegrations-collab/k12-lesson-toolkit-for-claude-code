# 5.2 Use Multiple Tools for Construction, Composition, and Creativity

## Summary

Consideration 5.2 sits under [[expression-and-communication]] in
[[multiple-means-of-action-and-expression]]. CAST's overview page condenses it to share
thoughts and ideas using tools that complement the learning goal. It is about **the tools
used to execute within a chosen medium** (spell checkers, CAD software, sentence starters,
manipulatives), not the medium itself (5.1) and not the practice needed to get fluent
with a tool (5.3).

## When to reach for it

Reach for 5.2 when a learner has a medium (chosen or fixed by the standard) but is
bottlenecked by the tools available to produce within it: writing is fine as the
medium, but drafting by hand is what's costing time and quality.

| The actual problem | Where to go instead |
|---|---|
| The medium/format itself is the barrier, not the tools within it | [[multiple-media-for-communication]] (5.1) |
| Tools are fine but the learner needs graduated practice to use them well | [[build-fluencies-with-graduated-support]] (5.3) |
| The tool set itself privileges some learners' modes of expression over others | [[biases-in-modes-of-expression]] (5.4) |
| General access to assistive technology across the whole learning environment | [[access-to-assistive-technologies]] (4.2) |

The distinction from 4.2 is scope: 4.2 is Guideline 4's access-level consideration and
covers the environment broadly. 5.2 is specifically about tools for **creating and
composing**: the narrower, task-level layer of the same underlying idea.

## How it works

CAST frames this as a habit problem before it is a resource problem:

> Without being prompted to consider contemporary tools, educators and instructional
> designers often depend on the tools they've grown accustomed to.

It names four costs of defaulting to traditional tools: it does not prepare learners
for their future, it limits the range of content and methods that can be used, it
restricts learners' ability to express what they know, and ("most importantly" per the
source) it restricts which learners can succeed at all.

The source names generative AI explicitly as a live example of the pattern: "generative
artificial intelligence (AI) has become a necessary consideration when designing
learning experiences around composition." The source does not go further than that:
no guardrails, no guidance on when AI use is appropriate to a construct and when it
substitutes for the skill being assessed. That is a real gap, not an omission on this
page; see the construct-shift caution below.

The same bounding exception structure as 5.1 applies here:

> Unless a goal is focused on learning to use a specific tool (e.g., learning to draw
> with a compass, learning a specific programming software), learning environments
> should embed a range of options for construction, composition, and creativity.

## In practice

CAST's design options, listed under this consideration:

- Use spell checkers, grammar checkers, word-prediction software.
- Use speech-to-text software (voice recognition), human dictation, recording.
- Use calculators, graphing calculators, geometric sketch pads, or pre-formatted graph
  paper.
- Use sentence starters or sentence strips.
- Use story webs, outlining tools, or concept mapping tools.
- Use Computer-Aided-Design (CAD), music notation (writing) software, or mathematical
  notation software.
- Use virtual or concrete mathematics manipulatives (e.g., base-10 blocks, algebra
  blocks).
- Use web applications (e.g., collaborative applications, animation, presentation).

**A worked pass.** A persuasive-essay assignment sits under a writing standard, so the
medium is fixed: 5.1 is not open, because the medium is the construct. 5.2 still is:
word prediction, speech-to-text for drafting, outlining tools, and sentence starters all
support production of the *same* written argument without changing what is being
assessed. This is the case that makes the 5.1/5.2 split concrete: a goal can be firm
on medium and flexible on tools at the same time.

## Gotchas & constraints

- **The tool exception mirrors 5.1's medium exception.** Where the goal is learning to
  use a specific tool (a compass, a particular programming environment), opening the
  tool set is construct-shift, the same way opening the medium is when the medium is
  the construct. Check which one, if either, the goal actually names.
- **Generative AI is flagged, not resolved.** CAST names it as a "necessary
  consideration" without specifying when tool-assisted composition changes what a
  construct measures. Where the goal is the learner's own reasoning or written skill,
  AI-assisted tools raise a live [[construct-irrelevant-variance]] question this source
  does not settle.
- **Tool access is not tool fluency.** Handing a learner eight new tools without
  practice time shifts the burden rather than removing it; pair a widened tool set
  with [[build-fluencies-with-graduated-support]] rather than assuming access alone
  does the work.
- **Do not conflate this with 4.2.** 4.2 covers assistive and accessible technology
  across the environment generally; 5.2 is the composition-specific layer sitting
  inside a different guideline.
