## Three things this reference is firm about

**UDL is not accessibility compliance.** WCAG conformance and an IEP accommodation are legal
obligations about access. UDL is a design stance about reducing the need for retrofit. Meeting
one does not discharge the other, and treating them as the same thing is the most common
category error in the field. See `wiki/trap/`.

**Firm goals, flexible means.** The goal does not bend. If the construct is "can this student
construct a similarity proof", then offering an alternative that removes the proof has changed
what is being measured, not how it is accessed. Distinguishing the two is the whole skill, and
it is why `concept/construct-irrelevant-variance` matters more than any checklist.

**The evidence base is uneven and this reference says so.** UDL's design principles rest on
better evidence than UDL's outcome claims do. Pages that draw on outcome literature say what
that literature does and does not support, including where implementation fidelity makes a
result hard to read. Learning styles, in particular, are not part of this.
